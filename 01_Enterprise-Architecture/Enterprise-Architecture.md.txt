# Enterprise Security Architecture

## Purpose

This document defines the representative enterprise technology
architecture and major security trust zones used by MediCare Health
Australia.

The architecture is fictional and is designed to support security
risk assessment, control implementation, incident simulation and
security assurance activities.

---

# Architecture Principles

The architecture follows the following security principles:

1. Least privilege
2. Defence in depth
3. Network segmentation
4. Centralised identity
5. Centralised security monitoring
6. Protected backup and recovery
7. Separation of administrative functions
8. Controlled access to sensitive clinical information
9. Logging of security-relevant activity
10. Explicit trust rather than unrestricted connectivity

# High-Level Data and Security Flow

External services do not receive unrestricted access to internal
systems.

Representative workflow:

Internet / External Services
        |
        v
Security Edge
        |
        +--------------------------+
        |                          |
        v                          v
Corporate User Zone         Cloud Services
        |
        v
Identity Services
        |
        +--------------------------+
        |                          |
        v                          v
Clinical User Zone     Clinical Application Zone
                                   |
                                   v
                           Patient Information
                                   |
                                   v
                          Backup / Recovery

Security-relevant events from representative systems are forwarded
to the Security Management Zone for monitoring and investigation.

---

# Segmentation Principle

A system being connected to the enterprise network does not imply
that it should communicate with every other enterprise system.

Communication between zones should be based on:

- documented business need;
- approved protocols;
- minimum required ports;
- authenticated access;
- least privilege;
- logging and monitoring;
- risk assessment.

---

# Student Lab Limitation

The physical and logical segmentation of a real healthcare enterprise
cannot be reproduced at full scale within the student environment.

Representative virtual networks and host controls will therefore be
used to demonstrate selected segmentation and access-control
principles.

The project will clearly distinguish between implemented controls
and enterprise design recommendations.
