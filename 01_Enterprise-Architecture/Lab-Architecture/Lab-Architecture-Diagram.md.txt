# 1. Purpose

This document defines the requirements for the technical laboratory
architecture diagram.

The final architecture diagram will be created manually using an
appropriate diagramming tool.

Creating the diagram manually is intentional because architecture
diagramming is itself a project learning objective.

---

# 2. Architecture Layers

The final diagram should show four major layers.

## Layer 1 — Physical Host

Student Workstation

Attributes:

- Windows 11 Home 25H2;
- Intel Core Ultra 5 125H;
- 16 GB RAM;
- Oracle VirtualBox.

---

## Layer 2 — Local Virtual Laboratory

VirtualBox hosts the representative enterprise systems.

Planned systems:

- DC01;
- WIN-REC01;
- WIN-CLIN01;
- SEC-MON01;
- VULN01.

---

## Layer 3 — Security Services

Security capabilities include:

- Active Directory;
- DNS;
- Group Policy;
- Microsoft Defender;
- Windows Event Logging;
- Sysmon;
- Wazuh;
- vulnerability management;
- backup/recovery.

---

## Layer 4 — Cloud Environment

AWS educational environment.

Potential components:

- IAM;
- Security Groups;
- CloudTrail;
- selected project resources.

---
