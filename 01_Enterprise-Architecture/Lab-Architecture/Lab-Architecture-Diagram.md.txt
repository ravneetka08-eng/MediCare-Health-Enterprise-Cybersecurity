# Laboratory Architecture Diagram Specification

## Purpose

This document defines the requirements for the technical lab
architecture diagram.

The final diagram will be created using a dedicated diagramming tool
rather than treated as an ASCII diagram in project documentation.

---

# Diagram Requirements

The final diagram should include:

- security boundaries;
- network/subnet labels;
- system hostnames;
- system roles;
- major communication relationships;
- local/cloud distinction;
- legend;
- title;
- version/date.

The diagram must distinguish:

- implemented components;
- planned components;
- cloud components.

---

# Evidence

The final exported architecture diagram will be stored within the
repository in an appropriate documentation/diagram format.

The editable source should also be retained where practical.
