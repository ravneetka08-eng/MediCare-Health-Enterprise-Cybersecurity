# Enterprise Asset Inventory

## Purpose

This register identifies representative technology and information
assets used by MediCare Health Australia.

The asset inventory supports:

- cybersecurity risk assessment;
- system ownership;
- data classification;
- vulnerability management;
- access control;
- incident response;
- business continuity;
- security monitoring; and
- control assurance.

The enterprise environment described here is fictional.

Only selected assets will be implemented within the student laboratory.

---

# Asset Status

The following implementation classifications are used:

- **LAB** — technically implemented in the student laboratory.
- **AWS LAB** — implemented using the authorised AWS student environment.
- **SIMULATED** — represented using synthetic data or a controlled simulation.
- **DESIGN ONLY** — included in the enterprise architecture but not technically implemented.

# Asset Inventory Limitation

This inventory represents the assets required to support the project's
enterprise scenario.

It is not intended to represent every asset that would exist within
a real healthcare organisation.

Assets classified as LAB or AWS LAB will be implemented and tested
where practical.

Assets classified as SIMULATED will be represented using controlled
synthetic workflows or data.

Assets classified as DESIGN ONLY are included to demonstrate
enterprise architectural dependencies but will not be claimed as
technically implemented.
