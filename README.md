# MediCare-Health-Enterprise-Cybersecurity
# MediCare Health Australia
## Enterprise Cybersecurity Resilience & Patient Data Protection Program

### Project Status
🚧 In Development

### Project Overview

This project models a cybersecurity resilience and security-control
assurance program for a fictional Australian healthcare organisation.

The project uses a representative laboratory environment to demonstrate
enterprise cybersecurity concepts including:

- cybersecurity risk management
- identity and access management
- Essential Eight control assurance
- vulnerability management
- security hardening
- cloud security
- security monitoring and detection
- incident response
- digital forensics
- backup and recovery
- privacy and data-breach assessment
- security metrics and executive reporting

### Project Objective

Determine how a fictional healthcare organisation can reduce the
likelihood and impact of identity compromise, ransomware and
patient-data breaches while maintaining the availability of critical
clinical services and demonstrating measurable cybersecurity control
effectiveness.

### Important Disclaimer

This is an educational cybersecurity project conducted in an isolated,
authorised laboratory environment.

The organisation, users, patient records and incidents used throughout
the project are fictional.

No real healthcare organisation, patient information or production
healthcare system is used.
